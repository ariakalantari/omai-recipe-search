How recipe search works

This app retrieves recipes from a fixed English collection. It does not generate recipes or let a language model invent the answer.

Two ways to search

Describe a dishWrite naturally in Swedish, English, Spanish, or another language supported by the multilingual model.
Use ingredientsList what you have. Results may still require additional ingredients.

Four clear ranking signals

  1. 1
    Ingredient overlap

    Canonical ingredient terms reward recipes that cover what you listed.

  2. 2
    Lexical similarity

    Character-based TF-IDF catches exact wording and many misspellings.

  3. 3
    Semantic similarity

    Local multilingual embeddings connect fuzzy meaning across languages.

  4. 4
    Hybrid ranking

    A small weighted formula combines the signals and keeps every score inspectable through the API.

What happens with a broad request?

The app cannot know what you have eaten before. For requests such as “surprise me,” it favors less common ingredient combinations in this collection and reduces repetitive results. Other unclear requests receive varied ideas plus a suggestion for refining the search.

Where AI fits

The main AI technique is the local multilingual embedding model. An optional Azure language model can help extract constraints from complex wording. It returns structured fields only. The local ranker still chooses the recipes, and the app continues to work when Azure is disabled or unavailable.

Privacy, grounding, and limits

  • Cloud credentials stay on the server and are supplied through the host’s secret manager. They are never sent to the browser or stored in this repository.
  • If optional Azure interpretation is enabled, the backend may send the search text to that configured service. This application does not persist search queries.
  • Cards use the source description when it exists. A factual title-and-ingredient summary is used when it does not. Missing history or nutrition is never invented.
  • Ingredient exclusions improve ranking but are not an allergy or dietary safety guarantee.
